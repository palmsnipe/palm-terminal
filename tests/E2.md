# Tungsten E2 verification

CloudpilotEmu's `cp-uarm` ran a Tungsten E2 at 100 MIPS with a supplied E2 session and a disposable FAT SD image. An isolated OpenSSH 10.0 server used its default algorithm lists and `RekeyLimit 64K`. The server was reachable only through the local test harness.

The PRC installed and launched on the E2. Password login and Ed25519 login both reached a PTY. The Ed25519 tests used an encrypted desktop key imported from SD and a second key generated on the Palm, exported as a public key, and authorized on the server. The OpenSSH log confirmed that the generated public key was the one used for authentication.

`stty size` reported 29×53 in the normal view and 26×53 with the line entry field open. BusyBox `top` and `vi` ran in the terminal, and a 100,000-byte transfer exercised rekeying. Color, UTF-8 line drawing, and scrollback were visible in the E2 display. The app returned to the key list when an import was cancelled and to the connection form after a remote shell closed. A connection without a seed prompted for setup. After the server was restarted with another host key, the Palm blocked the connection before user authentication. The host harness also completed the same transfer with an OpenSSH server configured for Curve25519 and an ECDSA P-256 host key.

## Measurements

| Operation | Initial build (`bee80c1`) | Optimized build |
|---|---:|---:|
| TCP and SSH to interactive PTY, with key already unlocked | 3.43–3.44 s | 0.33 s |
| TCP and SSH to interactive PTY, with password already entered | 2.14–2.18 s | 0.31–0.32 s |
| Read and verify an encrypted desktop Ed25519 key | 10.27 s | 7.76 s |
| Encrypt a stored-key container | 13.12 s | 10.35 s |
| Unlock an app-stored Ed25519 key | 13.54 s | 10.33 s |
| Show a marker after rendering 12,000 bytes of scrolling output | 20.46–27.94 s | 6.34–7.34 s |

Both builds used the same E2 session, emulator speed, encrypted input key, and local OpenSSH fixture. Handshake and key timings use Palm ticks at 100 Hz. The scrolling test measured desktop wall time from Enter to the first screenshot with the red marker, with two fresh sessions per build. The marker follows 12,000 bytes of `data` lines from the server, before the PTY's line-ending conversion.

The optimized build uses wolfCrypt's faster Curve25519 and Ed25519 implementations, performs the repeated bcrypt expansion in ARM code, and polls for cancellation between rounds. It renders glyphs directly into the Palm row bitmap from ARM. Stored keys use OpenSSH AES-256-GCM with 32 bcrypt rounds. The release PRC grew by 54 KiB to 476 KiB. The observed Palm dynamic-heap delta after the scrolling test grew from 944 KiB to 1,001 KiB, including the ARM arena.

On a copy of an E2 session from the initial build, the optimized PRC loaded the saved profile, cancelled an in-progress unlock, then unlocked the original key and authenticated to OpenSSH. A separate E2 run finished a 100,000-byte single-line stream, with the server log confirming successful rekeys. The ARM expansion also matched the upstream C implementation word for word across 64 test cases on an emulated ARM926.

## Reproduce

Install the PRC in a disposable E2 session with native NetLib redirection. Use a fresh desktop seed and a synthetic OpenSSH Ed25519 key on the SD image. Configure a local OpenSSH test account for password and key authentication, then follow the Seed setup, Keys, and Connect workflows in the README.

```sh
cp-uarm --device e2 --net-native --mips 100 --sd test-card.img e2-test.session
```

Use the emulator CLI's `install`, `launch`, and `screenshot` commands to inspect the Palm. To collect timings and heap measurements, build a profiling PRC in a separate build directory. With writable SD media, this build records timings and allocation counts in `PT-*.TXT` at the card root.

```sh
make BUILD_DIR="$PWD/build/profile" PALM_PROFILE=1
```

For the scrolling test, enter the following command in the remote shell and time from Enter until the top row turns red.

```sh
yes data | head -c 12000; printf '\033[2J\033[H\033[41m%53s\033[0m' ''
```

A physical Tungsten E2 was unavailable for verification.
